## Замечания по работе

Самое интересное наблюдение из первой лабораторной: после смены роли сервисного аккаунта со Storage Admin на Compute Viewer копирование файлов из бакета продолжило работать. Оказалось, что роль действительно снялась, а доступ к файлам шел не через нее, а через настройки самого бакета, который открыт публично. Проверил это обращением к файлу без авторизации, ответ 200.

Вывод, который стоит запомнить: права в облаке складываются из прав аккаунта и прав самого ресурса, и чтобы закрыть доступ к данным, смены роли недостаточно.
